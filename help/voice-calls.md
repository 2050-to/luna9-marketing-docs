title: Voice-call basics
description: How live calls work, how to allow the microphone, and how to pick a voice.
---

Live calls are on the **Pro** plan (card or a wallet that holds 1,000,000 $LUNA9). Voice notes are on Base. Live calls are not.

## Start a call

1. Open chat.
2. Choose **Call Luna Nine**.
3. Allow the microphone when the browser asks.

If the call control is dimmed, the account is not on Pro. See [Plans and pricing](/help/plans-and-pricing/).

## Microphone

The microphone turns on only while you are on a call or sending a voice note.

If access is blocked, allow the mic for luna9.space, then try again. If another app is using the microphone, close that app first. If this device has no microphone, calls cannot capture audio here.

## Which voice Luna uses

Open **Settings**. Pick feminine or masculine. Calls and voice notes both use that pick.
